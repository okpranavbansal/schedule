## Architecture & Features

- **Circadian Rhythms & Chronotype Matching**: Structured around biological Peak, Dip, Rebound, and Rest waveforms.
- **Dynamic Live IST Clock & Block Tracker**: Real-time indicator of the current active block and countdown to the next block.
- **Three Core Operational Modes**:
  - `⚡ Weekday Protocol`: P0 Career Sprint (DSA & CKA), Wyzard SRE Deep Work, 8k step stamina, early dinner curfew (7:30 PM).
  - `🚀 Saturday Build Sprint`: 4-hour unbroken flow state on Tier-3 Bypass high-signal portfolio projects.
  - `🔄 Sunday GTD Reset`: Weekly Review (Get Clear, Get Current, Get Creative), LinkedIn progress note, and weekly block planning.
- **Interactive 1-3-5 Priority Planner**: Persisted locally via `localStorage`.
- **Integrated Focus & Ultradian Timer**: 90m (Ultradian cycle), 50m (Deep focus), and 25m (Pomodoro sprint).
- **One-Click Exports**:
  - Copy formatted Markdown block directly into today's Obsidian Daily Note.
  - Download `.ics` iCalendar feed for Google Calendar / Apple Calendar.
